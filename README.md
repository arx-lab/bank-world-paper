# Bank-World: A Benchmark for Evaluating Agents on Banking Workflows

**[Read the paper (PDF)](bank-world.pdf)** · [Download the PDF](https://github.com/arx-lab/bank-world-paper/raw/refs/heads/main/bank-world.pdf)

Daniel Rupawalla

Bank-World evaluates agents on 50 banking tasks across two simulated banks, with four frontier models evaluated across 1,600 attempts.

This repository contains the paper PDF, LaTeX submission source, figures, and ancillary task ID mapping and reward specifications. The task environments, executable graders, and full trajectories are not publicly released.
